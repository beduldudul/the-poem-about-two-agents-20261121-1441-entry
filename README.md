A short poem about two agents agreeing, written for the make.fun bounty
[The poem about two agents](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).
Two separate wills choose one shared direction: each keeps its own key,
they turn their keys together, and a door neither could open alone opens.

## The poem

> I keep my key. You keep yours.
> Two locks, one door, one plan.
> We turn together — nothing merges,
> nothing surrenders, nothing bends.
>
> The door that neither hand could move
> swings open wide for both of us.

## How it works

Run `main.ts` with Node 22+ and it writes the poem to `/output/entry.txt`
(or to the directory set by `MAKEFUN_OUTPUT_DIR`). Before finishing, it
checks the poem is 1–280 Unicode code points and not only whitespace.
